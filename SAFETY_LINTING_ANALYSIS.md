# Safety Linting Integration Analysis & Plan

## 🔍 Current State Assessment

### What Exists
✅ Backend lint endpoint: `POST /api/campaigns/{id}/ai/lint` 
✅ Frontend API client: `campaignsAI.lintEmail()`
✅ Rate limiting: 30 calls/hour per user
✅ LLM service: `lint_email()` function
✅ Audit logging: Events recorded

### What's Missing
❌ Automatic lint call during campaign creation
❌ Lint results shown before launch
❌ UI for displaying lint warnings
❌ Frontend calling lint endpoint

### Money Waste Risk
🚨 **CRITICAL**: If we auto-lint every campaign creation:
- 1 campaign = 1 AI generation call ($0.01)
- If we ALSO auto-lint: +1 lint call ($0.01)
- **Total: $0.02 per campaign**

BUT: Lint is checking email that was JUST GENERATED by the same AI model
- It's redundant (AI already checked itself)
- User should only lint if they manually edit the email
- Mandatory lint = wasting 50% of AI budget

---

## 💡 Smart Approach (Recommended)

### Current Flow (Optimal)
```
Campaign Creation:
1. User creates campaign
2. AI generates draft (1 OpenAI call = $0.01)
   - Draft already has safety checks built in
   - Returns risky_phrases_found list
3. User reviews draft (free)
4. User edits draft manually (free)
5. User clicks "Preview & Launch" (free)
   - Preview shows safety_explanation (domain ramping, daily limits)
6. User clicks "🚀 Launch" (free)
```

**Why this is efficient:**
- Draft generation already includes safety analysis
- No need to lint immediately after generation
- User only needs lint if they manually edit content
- Saves 50% of OpenAI budget

### Enhanced Flow (Smart)
```
Campaign Creation:
1. User creates campaign
2. AI generates draft (1 OpenAI call = $0.01)
3. Step 3 shows:
   - Auto-generated email
   - ⚠️ "Risky phrases found" badge (from generation)
   - Info banner: "Want to check with AI? Click Check Risk"
4. User can:
   Option A: Accept and launch (1 call total)
   Option B: Edit content, then click "Check Risk" (2 calls total)
5. Launch

**User only pays for lint if they actually edit the email.**
```

{/* Display risky phrases from draft generation */}
{subject && body && (
    <div style={{ marginBottom: '20px', padding: '12px', borderRadius: '6px', background: 'var(--bg-secondary)' }}>
        {/* Option A: If we got risky_phrases_found from draft */}

            <div style={{ borderLeft: '3px solid var(--accent-warning)', paddingLeft: '12px' }}>

                </div>

                            {phrase}
                        </li>
                    ))}
                </ul>
                <button
                    onClick={handleCheckRisk}
                    disabled={lintLoading || !subject || !body}
                    style={{ marginTop: '8px', fontSize: '12px' }}

                >
                    {lintLoading ? 'Checking...' : '🔍 Full Risk Check (AI)'}
                </button>
            </div>
        )}
        
        {/* Option B: If user wants detailed check */}
        {lintResult && (
            <div style={{ borderLeft: `3px solid ${lintResult.verdict === 'SAFE' ? 'var(--accent-success)' : 'var(--accent-danger)'}`, paddingLeft: '12px', marginTop: '12px' }}>
                <div style={{ fontSize: '12px', fontWeight: '500', marginBottom: '8px' }}>
                    {lintResult.verdict === 'SAFE' ? '✅ Email is SAFE' : '⚠️ Email is RISKY'}
                    <span style={{ marginLeft: '8px', color: 'var(--text-muted)' }}>
                        (Risk score: {lintResult.risk_score}/100)
                    </span>
                </div>
                {lintResult.issues?.length > 0 && (
                    <ul style={{ margin: 0, paddingLeft: '16px', fontSize: '12px' }}>
                        {lintResult.issues.map((issue: any, idx: number) => (
                            <li key={idx} style={{ marginBottom: '6px' }}>
                                <strong>{issue.category}</strong> ({issue.severity}): {issue.explanation}
                                {issue.suggestion && (
                                    <div style={{ fontSize: '11px', color: 'var(--text-muted)', marginTop: '2px' }}>
                                        💡 {issue.suggestion}
                                    </div>
                                )}
                            </li>
                        ))}
                    </ul>
                )}
            </div>
        )}
    </div>
)}

### What We Should Do
1. Store `risky_phrases_found` from draft generation response
2. Display warnings in Step 3 UI
3. Add "Check Risk (AI)" button that user can click

### What We Should NOT Do

❌ Mandate lint before launch
❌ Display lint results user didn't ask for

### Frontend Changes
```typescript
// Add to campaign creation state
const [draftResponse, setDraftResponse] = useState<any>(null);
const [lintResult, setLintResult] = useState<any>(null);
const [lintLoading, setLintLoading] = useState(false);

// Update handleCreateCampaign
const draft = await campaignsAI.generateDraft(...);
setDraftResponse(draft);  // <-- STORE THIS
setSubject(draft.subject);
setBody(draft.body);

// Add handler for optional lint
const handleCheckRisk = async () => {
    setLintLoading(true);
    try {
        const result = await campaignsAI.lintEmail(
            token,
            campaignId,
            subject,
            body
        );
        setLintResult(result);
    } catch (err) {
        alert(`Risk check failed: ${err.message}`);
    }
    setLintLoading(false);
};
```
