## 📞 Need Help?

### Common Issues

**Form not submitting?**
- Check `/app/api/waitlist/route.ts` exists
- Rebuild: `npm run build`
- Check browser console for errors

**Styles look wrong?**
- Clear cache: Ctrl+Shift+Delete
- Restart dev server: npm run dev
- Check globals.css is imported

**Mobile menu broken?**
- Refresh page
- Check for JavaScript errors
- Ensure navbar.tsx has 'use client'

**Colors not changing?**
- Edit `/app/globals.css` directly
- Update button gradient classes
- Rebuild: npm run build
